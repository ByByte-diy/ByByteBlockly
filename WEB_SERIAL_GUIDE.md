# Web Serial API - Інструкція використання

## 🌐 Підтримка браузерів

Web Serial API підтримується в:
- ✅ **Chrome** 89+
- ✅ **Edge** 89+
- ✅ **Opera** 75+
- ❌ **Firefox** - не підтримується
- ❌ **Safari** - не підтримується

## 🔒 Безпека та дозволи

Web Serial API вимагає:
1. **HTTPS** або `localhost` для безпеки
2. **Дозвіл користувача** для кожного пристрою
3. **Взаємодія користувача** (клік кнопки) для вибору пристрою

## 📋 Як підключити Arduino/пристрій

### Крок 1: Підключіть пристрій
Підключіть Arduino або інший пристрій до USB порту комп'ютера.

### Крок 2: Відкрийте список пристроїв
У додатку натисніть кнопку **"Список пристроїв"** або **"Select Device"**.

**Якщо список порожній:**
- Це нормально! Web Serial API не показує пристрої автоматично
- Ви побачите підказку: `"Click 'Connect' to select a device..."`

### Крок 3: Натисніть "Connect" (Підключити)
При натисканні кнопки з'явиться **діалог вибору пристрою** від браузера:

```
┌─────────────────────────────────────┐
│  Select a serial port               │
├─────────────────────────────────────┤
│  ○ Arduino Uno (COM3)               │
│  ○ USB Serial Device (COM5)         │
│  ○ CH340 USB-SERIAL (COM7)          │
├─────────────────────────────────────┤
│  [Cancel]              [Connect]    │
└─────────────────────────────────────┘
```

### Крок 4: Виберіть пристрій
- Оберіть ваш Arduino/пристрій зі списку
- Натисніть **"Connect"**
- Браузер запам'ятає ваш вибір для наступних разів

### Крок 5: Перевірте підключення
Статус підключення зміниться на **"Connected"** (Підключено).

## ⚠️ Типові помилки та рішення

### Помилка: "Web Serial API not supported"
**Причина:** Ваш браузер не підтримує Web Serial API.

**Рішення:**
- Використовуйте **Chrome**, **Edge**, або **Opera**
- Оновіть браузер до останньої версії
- Або використовуйте **Electron версію** додатку

---

### Помилка: "No serial port selected"
**Причина:** Користувач закрив діалог без вибору пристрою.

**Рішення:**
- Натисніть кнопку "Connect" ще раз
- Оберіть пристрій у діалозі та натисніть "Connect"

---

### Помилка: "Port is already open"
**Причина:** Пристрій вже відкритий в іншій вкладці або програмі.

**Рішення:**
- Закрийте інші вкладки з додатком
- Закрийте Arduino IDE, PlatformIO, або інші програми
- Від'єднайте та підключіть пристрій знову

---

### Помилка: "Device may be disconnected"
**Причина:** Пристрій від'єднано під час роботи.

**Рішення:**
- Перевірте USB кабель
- Підключіть пристрій знову
- Натисніть "Connect" ще раз

---

### Список пристроїв порожній
**Причина:** Web Serial API не показує пристрої до отримання дозволу.

**Рішення:**
- Це **нормальна поведінка** для Web Serial API
- Просто натисніть **"Connect"** - з'явиться діалог вибору
- Після першого підключення пристрій з'явиться у списку

## 🔧 Технічні деталі

### Як працює Web Serial API

1. **`listPorts()`** - повертає тільки **раніше авторизовані** порти
2. **`requestPort()`** - показує діалог для **вибору нового** пристрою
3. **Дозволи** зберігаються в браузері

### Обмеження Web Serial API

- ❌ Не можна отримати список всіх USB пристроїв без дозволу
- ❌ Потрібна взаємодія користувача (клік) для `requestPort()`
- ❌ Кожен сайт має свої окремі дозволи
- ✅ Дозволи зберігаються після перезавантаження сторінки

### Порівняння з Electron

| Функція | Web | Electron |
|---------|-----|----------|
| Автоматичний список пристроїв | ❌ | ✅ |
| Потрібен дозвіл користувача | ✅ | ❌ |
| Підтримка всіх браузерів | ❌ | ✅ |
| Не потрібна установка | ✅ | ❌ |

## 💡 Поради

### Для розробників

```typescript
// Web Serial API вимагає user interaction
button.addEventListener('click', async () => {
  // ✅ Працює - викликається з обробника кліку
  await serialService.connect('request-new-port');
});

// ❌ НЕ працює - викликається автоматично
window.onload = async () => {
  await serialService.connect('request-new-port'); // ERROR!
};
```

### Для користувачів

1. **Завжди використовуйте кнопку "Connect"** для першого підключення
2. **Дозвольте доступ** коли браузер запитує
3. **Пристрій запам'ятається** і наступного разу з'явиться в списку
4. **Не закривайте діалог** - оберіть пристрій

## 🐛 Звітувати про проблеми

Якщо Web Serial API не працює:

1. Перевірте версію браузера (Chrome 89+)
2. Переконайтеся що сайт відкритий через HTTPS або localhost
3. Перевірте консоль браузера (F12) на помилки
4. Спробуйте використати Electron версію додатку
